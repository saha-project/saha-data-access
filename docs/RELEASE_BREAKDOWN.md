Zenodo and AWS v1 hold the **same 126 objects** (same sample ids, same cells, same labels). AWS swaps in full-resolution morphology for the 49 CosMx objects; the 52 Dulai and 25 Xenium (vendor-native imagery) objects are one store serving both. AWS sizes are the stores as uploaded to s3://saha-public, including the H&E images (same-section, serial-section and unaligned) added in October. Zenodo sizes come from zenodo/combined_manifest.csv, which predates the 2026-10-09/10 repackaging that added the H&E (the zips on Cayuga now total 199.0 GB, every record still under 50 GB); regenerate the manifest's sizes and MD5s before deposit. v2 cores: 31 resolved on PROS_A2; PROS_A3 is not yet resolved.
